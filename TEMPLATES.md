# Resume & CV Templates

This resume builder now includes 9 professional templates catering to different industries and international standards.

## Template Overview

### 1. Modern Template
**Best for:** Tech professionals, startups, creative industries
- Clean, contemporary design with colored header
- Skills displayed as modern tags
- Emphasis on visual hierarchy
- Customizable accent colors

### 2. Classic Template
**Best for:** Traditional industries (law, finance, government)
- Professional serif font (Times Roman)
- Centered header with clear sections
- Conservative styling
- Universal appeal

### 3. Minimal Template
**Best for:** Designers, minimalists, modern professionals
- Ultra-clean layout
- Maximum white space
- Border-left highlights
- Subtle visual elements

### 4. Executive Template
**Best for:** Senior management, C-level positions
- Two-column layout with sidebar
- Professional gray sidebar
- Skills and certifications highlighted
- Premium appearance

### 5. Creative Template
**Best for:** Artists, marketers, designers
- Bold, colorful design
- Large header with personality
- Creative section styling
- Eye-catching skill badges

### 6. Technical Template
**Best for:** Software developers, engineers, IT professionals
- Monospace font (Courier)
- Code-style comments for sections
- Gray code blocks
- Developer-friendly aesthetic

### 7. Academic CV Template ⭐ NEW
**Best for:** Researchers, professors, PhD students, academics
- Traditional academic formatting
- Education prioritized at top
- Research-focused sections
- Publication-ready layout
- Sections optimized for:
  - Research Interests
  - Academic Appointments
  - Research Projects
  - Awards & Honors
  - Professional Memberships
  - Research Skills & Methodologies

### 8. International (Europass) CV Template ⭐ NEW
**Best for:** European job markets, international applications
- Europass-style two-column design
- Sidebar for personal info and skills
- Clear section headers with gray background
- International standard formatting
- Comprehensive sections including:
  - Work Experience
  - Education and Training
  - Projects
  - Volunteer Experience
  - Awards and Achievements

### 9. Portfolio Template ⭐ NEW
**Best for:** Freelancers, designers, developers with project portfolios
- Visual project showcase
- Hero section with large header
- Featured projects with tech stacks
- Experience displayed in grid format
- Project-centric layout
- Perfect for:
  - Web developers
  - Graphic designers
  - UX/UI designers
  - Digital creatives
  - Freelancers

## Template Features

All templates support:
- **Customizable Colors:** Choose from 7 accent color presets
- **Font Options:** Helvetica, Times-Roman, Courier
- **Section Reordering:** Drag and drop to reorganize sections
- **Section Visibility:** Show/hide any section
- **Multiple Sections:** Experience, Education, Skills, Projects, Certifications, Languages, Volunteer, Awards
- **ATS Optimization:** All templates are ATS-friendly
- **PDF Export:** High-quality PDF generation
- **Responsive Preview:** Real-time preview as you edit

**Finance/Law:** Classic, Executive, International

**Creative:** Creative, Portfolio, Modern

### By Career Stage

**Entry Level:** Modern, Minimal, International
**Mid-Career:** Modern, Classic, Technical
**Senior/Executive:** Executive, Classic
**Academic:** Academic CV

### By Region

**North America:** Modern, Classic, Technical, Executive
**Europe:** International (Europass), Classic
**Academic Worldwide:** Academic CV
**Creative Worldwide:** Portfolio, Creative

## Customization Tips

1. **Academic CV:** Use the "Projects" section for research projects, "Certifications" for professional memberships
2. **International CV:** Add all languages with proficiency levels for European standards
3. **Portfolio:** Focus on your top 3-5 projects with detailed descriptions and tech stacks
4. **Technical:** Keep it concise, emphasize skills and projects over lengthy descriptions
5. **Executive:** Highlight leadership experience and quantifiable achievements
